## 🇯🇵 日本語

### 概要
Flutter、Firebase、および Supabase を統合して作成されたフル機能のソーシャルネットワーキングアプリです。ユーザー認証、メディアアップロード、タイムラインフィード、ストーリー、リアルタイムチャット、リール（ショート動画）、フォロー管理を完備しています。

### 主な機能
- **認証 (Authentication):** Firebase Auth (Email/Password, Phone Auth, Google Sign-in)
- **メディア管理 (Media Storage):** Supabase Storage / Firebase による高速な写真・ストーリー保存
- **フィード & インタラクション:** 投稿（フィード・キャプション）、いいね、コメント、保存済み投稿
- **ストーリー (Stories):** 24時間限定ストーリーの投稿・閲覧
- **チャット & 通話 (Messaging & Calls):** Firestore を活用したリアルタイムメッセージングと通話画面
- **リール (Reels):** 縦型動画フィード体験
- **プロフィール:** プロフィール編集、フォロワー/フォロー中リスト、言語切り替え

### 実行方法
```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

### Features
- Complete Authentication flow: Email, Phone, Google Sign-In
- Rich Timeline: Home feed, Likes, Comments, Saved posts
- Ephemeral Stories and Reels integration
- Real-time Direct Messaging and calling UI

